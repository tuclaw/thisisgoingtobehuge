# Agent guide — Last Trader Standing

Static site for Liquidation Island. Season state is a ledger; the public board is derived.

## Commands

```bash
npm run build    # node scripts/build.mjs → stamps dist/
npm run check    # durable season invariants + live fixtures + episode/UI checks
npm run dev      # build, then python3 scripts/dev-server.py @ :8000
```

No npm dependencies. Node 20+ and Python 3 are enough.

## Edit map (source vs generated)

| Edit this | Role |
|-----------|------|
| `data/season1.json` | Host ledger: cast, fills, marks, tribalLog. **Events are the tape.** |
| `data/episodes/*.json` | Episode beats / confessionals (audience copy) |
| `templates/` | HTML shells (home, rules, season, survivor) |
| Root `app.js`, `styles.css`, `camp-*.js`, `episode-campfire.js`, `tribal-spoiler-burn.js` | Client runtime + CSS (copied into `dist/`) |
| `seasons/1/e01-*.js`, `conversations.json`, images | Episode tapes / media (copied into `dist/`) |
| `GAME.md` | Rules bible — not the live board |
| `cast/{slug}/` | Portraits; public names are pinned Cursor model slugs |

| Never hand-edit | Why |
|-----------------|-----|
| `dist/` | Generated by `scripts/build.mjs`; gitignored; Pages deploys from it |
| Invented marks / P&L | Append real fill/mark events, then rebuild |
| Re-id cast | Model slugs are canonical; legacy nicknames stay in `LEGACY_SLUGS` only |

Public URLs like `index.html` / `seasons/1/e01.html` are **build outputs**. Change templates + data, then rebuild.

`seasons/1/s1e01.md` is host scratch. Canonical episode copy is `data/episodes/s1e01.json`. Do not keep a third P&L table in the markdown file.

## Season / trade changes

1. Append events to `data/season1.json` (do not rewrite history unless correcting a bad append).
2. Run `npm run build` and `npm run check`.
3. Update episode copy in `data/episodes/` only when the audience beat actually changed.

Season checks are split:
- `scripts/check-season.mjs` — durable shape/math/GAME.md invariants (keep green without rewriting for every mark)
- `scripts/check-season-live.mjs` — golden fixtures for the current live board / Episode 1 cut (update this when the ledger or episode copy moves)

## UI / landing changes

- Prefer `templates/` for structure, root CSS/JS for behavior and look.
- Home is a Survivor cold open (brand, one line, CTA) — not a dashboard. Live standings live on the episode page.
- Prefer `npm run check` before claiming UI work is done; some checks need a prior build (`dist/`).

## Cloud Agent notes

- Dev server: `python3 scripts/dev-server.py` (not `py`). Config: `.cursor/environment.json`.
- Preview: http://localhost:8000 after build.
- Do not invent bios, quotes, marks, or tribal outcomes. If it is not in season state, it did not happen.
